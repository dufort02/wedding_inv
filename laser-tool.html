ส่งออก

ไฟล์หลักทุกระดับในไฟล์เดียว · XCS: Bitmap mode = Grayscale
ไฟล์เส้นอย่างเดียวเส้นดำบนพื้นขาว · ยิงรอบสองด้วยโหมด Threshold/Sketch ตำแหน่งเดิม → เส้นคมที่สุด
ไฟล์เฉพาะเฉด (ยิงซ่อม)เลือกเฉดที่ยิงแล้วไม่ติด → ได้ไฟล์ที่มีแค่เฉดนั้น ส่วนอื่นขาว · ห้ามขยับไม้ · วางขนาดและ X/Y เท่าไฟล์แรก
ตาราง Testแถบทุกระดับ (ขาว · เฉด 1–5 · ดำ) ไว้ยิงบนเศษไม้ก่อน ดูว่าเฉดไหนไม่ติด/เข้มเกิน แล้วปรับช่วงด้านบน

ขั้นตอนแนะนำ: ยิง ตาราง Test บนเศษไม้แผ่นเดียวกัน → ปรับช่วงเฉดให้ทุกเฉดติดและแยกกันออก → ยิง ไฟล์หลัก (Grayscale) → ถ้าอยากได้เส้นคมขึ้น ยิง ไฟล์เส้นอย่างเดียว ทับ (Threshold) ตำแหน่งเดิม
ไฟล์ทุกแบบขนาดเท่ากัน ใส่ขนาด W×H และ X/Y เท่ากันใน XCS แล้วจะซ้อนตรงกัน
