การ์ดแต่งงานออนไลน์ Palida & Pachaya — แก้ค่าต่าง ๆ ได้ที่ `CONFIG` ใน `index.html`

## ช่องทางร่วมอวยพร (RSVP แบบที่ 2)

ช่องทางร่วมอวยพร (ของขวัญ): อัปรูป QR เป็น `images/promptpay.png` → ขึ้นแทนกล่อง "QR code เร็ว ๆ นี้" เอง (ไม่มีเลขบัญชี/ปุ่มคัดลอกแล้ว)


## เชื่อม RSVP กับ Google Sheet

1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `Code.gs` → บันทึก
3. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** → ประเภท **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
4. อนุญาตสิทธิ์ แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
5. วาง URL ใน `CONFIG.RSVP_ENDPOINT` ของ `index.html`

ทดสอบ: เปิด URL `/exec` ในเบราว์เซอร์ ต้องเห็น `{"ok":true,...}`

> แก้ `Code.gs` ภายหลัง ต้อง **ทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่** ทุกครั้ง
> ถ้าเคยสร้างชีต `RSVP` จากโค้ดเวอร์ชันเก่า ให้ลบหรือเปลี่ยนชื่อชีตนั้นก่อน เพราะคอลัมน์เปลี่ยนแล้ว

## ย้ายไป Google Sheet ใหม่ / บัญชี Google ใหม่ (เช่น ชีตเดิมหาย)
1. ล็อกอินบัญชีใหม่ → สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script** → วางโค้ด `Code.gs` ทั้งไฟล์ (ตั้ง `STAFF_KEY` ด้วย) → บันทึก
2. เลือกฟังก์ชัน `setup` → ▶ เรียกใช้ → อนุญาตสิทธิ์ (บัญชีใหม่จะถามสิทธิ์ชีต/ไดรฟ์/อีเมลใหม่ทั้งหมด)
3. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป** · ดำเนินการในฐานะ: ฉัน · ผู้มีสิทธิ์เข้าถึง: ทุกคน → คัดลอก URL `/exec`
4. เปิด URL `/exec` ต้องเห็น `version: 4` → วาง URL ใหม่ใน `CONFIG.RSVP_ENDPOINT` ของ `index.html` (หน้า wishes / checkin อ่านจาก index.html เอง)
- แขกที่เคยตอบไว้: เปิดเว็บครั้งถัดไป เว็บจะ **ส่งคำตอบเดิม (+ ตัวละคร) เข้าชีตใหม่ให้เอง 1 ครั้ง** · คำอวยพรที่ส่งซ้ำจะเป็น "รออนุมัติ" ใหม่ · แขกที่ไม่กลับมาเปิดเว็บ ข้อมูลจะไม่กลับมา
- รูปตัวละครเก่าที่อยู่ใน Drive บัญชีเดิมจะไม่ถูกย้าย (ส่งใหม่จากเครื่องแขกตอนซิงก์)

## อัปเดตสคริปต์เวอร์ชันแอดมิน (ทำครั้งเดียว)

1. เปิด Apps Script ของชีต → วางโค้ดใหม่จาก `Code.gs` ทับทั้งหมด → บันทึก
2. เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน → กด **▶ เรียกใช้** → อนุญาตสิทธิ์ (ครั้งนี้จะขอสิทธิ์ส่งอีเมลเพิ่ม)
   - เพิ่มคอลัมน์ `ปักหมุด`, ตั้ง dropdown/สีของช่อง `แสดงบนเว็บ`, สร้างชีต **สรุป**
3. **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
   (URL `/exec` เดิมใช้ต่อได้ ไม่ต้องแก้ index.html)
4. รีเฟรชหน้า Google Sheet → จะเห็นเมนู **💌 งานแต่ง**
5. **เช็กว่า deploy แล้วจริง:** เปิด URL `/exec` ในเบราว์เซอร์ ต้องเห็น `"version":6` (เลขล่าสุด) และ `"approval":true`
   ถ้ายังเห็นแค่ `{"ok":true,"msg":"RSVP endpoint is running"}` = เว็บยังใช้สคริปต์ตัวเก่า → ทำข้อ 3 ใหม่ (ต้องเลือก **เวอร์ชันใหม่**)

## เพิ่มชิ้นส่วนตัวละคร

อัปโหลด 2 ไฟล์ต่อ 1 ตัวเลือก โดย**ใช้เลขถัดไป**และ**นามสกุล `.png` ตัวเล็ก**:
- `images/<หมวด>_<เลข>.png` เช่น `images/hair_6.png`
- `images/icons/<ไอคอน>_<เลข>_thumb.png` เช่น `images/icons/hair_6_thumb.png`

ชื่อหมวด/ไอคอนดูได้ที่ `LAYERS` ใน index.html (เช่น ที่คาดผม = `hair_accessories_6.png` + `icons/hair_acc_6_thumb.png`)
เว็บจะเจอไฟล์ใหม่เองอัตโนมัติ ไม่ต้องแก้โค้ด — แต่เลขต้องต่อเนื่อง (ถ้าข้ามเลข จะหยุดหาตรงเลขที่ขาด)

## ชิ้นที่สลับซ้าย-ขวาได้
- อัปไฟล์ 2 ด้านเป็น `<ชื่อหมวด>_<เลข>_L.png` และ `_R.png` (นามสกุล .png ตัวเล็ก) + ไอคอนรูปเดียว `icons/<thumb>_<เลข>_thumb.png`
- ใส่เลขนั้นใน `sides:[...]` ของหมวดใน `LAYERS` (ตอนนี้: ที่คาดผม `sides:[8]` ดอกชบา · ของบนหน้า `sides:[9]` หัวใจใต้ตา) → ไอคอนมีป้าย ⇄ และพาเลตมีปุ่ม ⇄ สลับด้าน (เริ่มต้นด้าน L)
- เลขที่มี 2 ด้านต้องใส่ `count` ให้ครอบคลุมเอง (ระบบหาไฟล์อัตโนมัติจะไม่เจอเพราะไม่มีไฟล์ชื่อ `_<เลข>.png`)

## รูปชิ้นส่วนสำเนาย่อ (กันแอปเด้งบนมือถือ)

- ถ้าต้องรันเอง: `python3 scripts/make_web_images.py` (หรือแท็บ Actions → Make web images → Run workflow)
- ไอคอน (`images/icons/`) ไม่ต้องย่อ

## บัตรเข้างาน QR · ผู้ติดตาม · เช็กอินหน้างาน (Code.gs เวอร์ชัน 4)
**ตั้งค่าครั้งเดียว**
1. ใน Code.gs ตั้ง `STAFF_KEY` เป็นรหัสทีมงาน (เช่น `'1912'`) — ว่างไว้ = ปิดหน้าเช็กอิน
2. วางโค้ดใหม่ใน Apps Script → รัน `setup` 1 ครั้ง (เพิ่มคอลัมน์ "ผู้ติดตามของ", "เช็กอิน" + บรรทัดสรุปใหม่) → ทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่ (เปิด URL /exec ต้องเห็น `version: 4`)

**แขก**
- ตอบรับ "ไปร่วมงาน" แล้ว ใต้บัตรเชิญจะมี **QR บัตรเข้างาน** (ลิงก์ไปหน้าเช็กอิน + รหัสแขก ไม่มีข้อมูลส่วนตัวใน QR)
- มามากกว่า 1 คน → ปุ่ม **"ส่งลิงก์ให้ผู้ติดตาม"** (ลิงก์เดียวใช้ได้ทุกคน) ผู้ติดตามเปิดลิงก์ → แต่งตัว + ใส่ชื่อ → ส่งบัตรเอง ไม่ต้องตอบ RSVP · ในชีตเป็นแถว mode `companion` จำนวนคน 0 (นับรวมในแขกหลักแล้ว)

**ทีมงาน — `checkin.html`**
- สแกน QR บนบัตรด้วยกล้องมือถือธรรมดา → เปิดหน้าเช็กอินของแขกคนนั้น → กด **ยืนยันเข้างาน** (บันทึกเวลาลงคอลัมน์ "เช็กอิน") · สแกนซ้ำจะขึ้นว่าเช็กอินแล้ว
- ครั้งแรกในเครื่องใส่รหัสทีมงาน (หรือเปิด `checkin.html?key=รหัส`) · ค้นหาชื่อได้ สำหรับแขกที่ไม่มีบัตร
- แท็บ **พิมพ์บัตร** = บัตรแบบตั๋ว 8 ใบ/A4 (ตัวละคร ชื่อ จำนวนคน QR) → พิมพ์ / บันทึก PDF · เลือกรวมผู้ติดตาม / เฉพาะที่ยังไม่เช็กอิน

## ทดสอบเกมแต่งตัว

- ปุ่มแว่นขยายมุมขวาล่างของรูป = ดูตัวละครแบบขยายเต็มจอ (แตะรูปเพื่อซูม 2.5 เท่า ลากเพื่อเลื่อน)

เปิด `https://palida-pachaya-wd.pages.dev/index.html?avatar`

- เข้าหน้าแต่งตัวทันที (ไม่มีหน้าปก/เพลง) → กด "ใช้ตัวนี้เข้างาน" → เห็น **บัตรเชิญ** เหมือนเว็บจริง + ปุ่มบันทึกรูป 2000px
- ด้านล่างมี **ตัวอย่างการ์ดอวยพรแบบรีวิว** (หน้าตาเดียวกับบนเว็บ) ลองเปลี่ยนข้อความและแบบตอบรับได้
- **ไม่บันทึกอะไรเลย และไม่ส่งเข้าชีต** — ไม่กระทบข้อมูลแขกจริงที่อยู่ในเครื่องเดียวกัน ส่งลิงก์ให้เพื่อนช่วยลองได้

## พฤติกรรมของแขก (สรุป)

- **ครั้งแรก:** เปิดคำเชิญ → แต่งตัวละคร → ได้บัตรเชิญ → ตอบ RSVP
- **กลับมาอีกครั้ง (เครื่อง/เบราว์เซอร์เดิม):** ข้ามหน้าแต่งตัว เห็นบัตรเชิญ + "คุณตอบรับแล้ว" พร้อมปุ่ม **แก้ไขคำตอบ**
- **แก้ไขคำตอบ:** อัปเดตแถวเดิมในชีต (ไม่เพิ่มแถวซ้ำ) — ถ้าแก้ข้อความอวยพร จะกลับไป "รออนุมัติ"; ถ้าแก้อย่างอื่น การ์ดที่อนุมัติ/ปักหมุดไว้ยังอยู่
- **เปลี่ยนเครื่อง/เบราว์เซอร์** (เช่น เปิดลิงก์ใน LINE แล้วเปิดใน Safari) = เหมือนแขกใหม่ → อาจได้แถวซ้ำ ดูได้ที่ชีตสรุป "ชื่อที่ตอบซ้ำ"
- **รูปตัวละคร:** ส่งเข้า Drive เป็น PNG พื้นใส 1500×1500 (พิมพ์สติกเกอร์ ~12 ซม. ที่ 300dpi) · ปุ่ม "บันทึกรูปตัวละคร" ให้แขกโหลด 2000×2000
- ก่อนใช้จริง ตั้ง `SHOW_SKIP: false` ใน index.html (ซ่อนปุ่ม "ข้าม" หน้าแต่งตัว)

## การจัดการคำอวยพร (แอดมิน)

ทุกอย่างทำใน Google Sheet ชีต `RSVP` — แก้แล้วหน้าเว็บเห็นทันที

| ต้องการ | วิธี |
|---|---|
| อนุมัติให้ขึ้นเว็บ | ช่อง **แสดงบนเว็บ** → `แสดง` หรือเลือกหลายแถว → เมนู 💌 → ✅ |
| ซ่อน | → `ไม่แสดง` หรือเมนู 💌 → 🚫 |
| ปักหมุดไว้บนสุด | ติ๊กช่อง **ปักหมุด** หรือเมนู 💌 → 📌 (การ์ดมีเทปแดงและหัวใจ) |
| แก้คำผิด | แก้ในช่อง `คำอวยพร` / `ชื่อ` ได้เลย |
| ลบถาวร | ลบทั้งแถว (รูปตัวละครยังอยู่ในโฟลเดอร์ Drive `Wedding Guest Avatars`) |

**โหมดอนุมัติ** — คำอวยพรใหม่จะเป็น `รออนุมัติ` (สีเหลือง) จนกว่าจะเปลี่ยนเป็น `แสดง`
ปิดโหมดนี้: ตั้ง `REQUIRE_APPROVAL = false` ใน Code.gs **และ** `WISH_APPROVAL: false` ใน index.html

**อีเมลแจ้งเตือน** — ทุกครั้งที่มีคนตอบ จะส่งไปที่อีเมลเจ้าของชีต
เปลี่ยนผู้รับ: `NOTIFY_EMAIL = 'a@gmail.com,b@gmail.com'` ปิด: `NOTIFY_EMAIL = ''`

## หน้ากำลังจัดเตรียม (รหัสลับ)
- ไฟล์ `js/gate.js` — ใช้กับ `index.html` และ `wishes.html` (หน้าเช็กอินมีรหัสทีมงานของตัวเองอยู่แล้ว)
- ช่องใส่รหัสซ่อนไว้ไม่ให้แขกเห็น — **แตะโลโก้ 5 ครั้งติดกัน** ช่องจะโผล่ · ใส่ครั้งเดียว เครื่องนั้นจะจำไว้
- หน้าทดสอบตัวละคร `index.html?avatar` เปิดได้โดยไม่ต้องใส่รหัส
- ส่งลิงก์ให้คนทดสอบเข้าได้เลย: `https://palida-pachaya-wd.pages.dev/?gate=รหัส`
- **เปิดเว็บจริง:** เปลี่ยน `var GATE_ON = true;` เป็น `false`
- **เปลี่ยนรหัส:** หาค่า SHA-256 ของรหัสใหม่ (เช่นค้นเว็บ "sha256 online" แล้วพิมพ์รหัส) แล้วเอาค่ามาใส่ใน `GATE_HASH` · เปลี่ยนรหัสแล้วทุกเครื่องต้องใส่ใหม่
- เป็นการซ่อนหน้าเว็บแบบง่าย ไม่ใช่ระบบความปลอดภัยจริง — คนที่เปิดดูโค้ดหรือรู้ที่อยู่ไฟล์รูปยังเข้าถึงไฟล์ได้

- **ขยับป้ายชื่อ:** ใน `index.html` ค้นคำว่า `cp-pin` จะเจอ 2 บรรทัด
  `<span class="cp-pin" style="--x:32%;--y:30%"><b>CAST 01 · PALIDA</b></span>`
  - `--x` = ระยะจาก**ซ้าย**ของรูป (0% ชิดซ้าย · 50% กลาง · 100% ชิดขวา) → เพิ่มเลข = ไปทางขวา
  - `--y` = ระยะจาก**บน**ของรูป (0% บนสุด · 100% ล่างสุด) → เพิ่มเลข = ลงล่าง
  - ตัวเลขคือตำแหน่ง **จุดกลมสีทอง** — ให้วางบนหัวหรือหน้าผากของแต่ละคน ป้ายชื่อจะลอยอยู่เหนือจุดเอง
  - ถ้าป้ายชิดขอบรูปจนล้น ขยับ `--x` เข้ามาทางกลางอีกนิด
- แก้ข้อความบนป้ายได้ในแท็ก `<b>...</b>` · ข้อความบนกระดานสเลต อยู่ใน `<figcaption class="cp-slate">` ถัดลงมา

## บันทึกการใช้งาน (Code.gs เวอร์ชัน 7–8)
- แท็บใหม่ **"บันทึก"** ในไฟล์ชีต (สร้างเองครั้งแรก · แยกจากตาราง RSVP และชีตสรุป): เวลา · ชื่อ · ทำอะไร · รหัสแขก · เปิดจาก (LINE / iPhone / Android / คอม)
- เหตุการณ์: **แต่งตัวเสร็จ**, **แต่งตัวใหม่**, **กลับมาเปิด** (แขกที่เคยแต่งตัว เปิดเว็บอีก — วันละครั้ง), **ตอบรับ / แก้คำตอบ**
- ดูว่าใครแต่งตัวแล้วแต่ยังไม่ตอบรับ: ชื่อที่มี "แต่งตัวเสร็จ" แต่ไม่มี "ตอบรับ"
- เก็บตั้งแต่ deploy เวอร์ชันนี้เป็นต้นไป (ย้อนหลังไม่ได้)
- เวอร์ชัน 8: คอลัมน์ **ค่าตัวละคร (JSON)** (เลขชิ้น + สี) เก็บตอน "แต่งตัวเสร็จ / แต่งตัวใหม่" — เผื่อแขกลืมตอบรับ
- อัปเดต: วางโค้ด `Code.gs` ใหม่ → ทำให้ใช้งานได้ → จัดการ → แก้ไข → **เวอร์ชันใหม่** · เช็ก `/exec` ต้องเห็น `"version":8`

## สถิติคนเข้าเว็บ (Cloudflare Web Analytics)
- Cloudflare → **Workers & Pages → palida-pachaya-wd → Metrics** → **Enable Web Analytics** (ฟรี ไม่ต้องแก้โค้ด — Cloudflare ใส่ให้ตอน deploy ครั้งถัดไป)
- เห็นจำนวนคนเข้า / หน้า / ประเทศ / อุปกรณ์ · ไม่เห็นชื่อ · เก็บตั้งแต่เปิดใช้

## ตราประทับ "ยังไม่ตอบรับ" (ธีม 3)
- แขกที่แต่งตัวแล้วแต่ยังไม่ตอบรับ เห็นตราสีแดงเอียงบนตั๋ว (กดแล้วเลื่อนไปฟอร์มตอบรับ) · ปุ่ม "ไปตอบรับ" เป็นปุ่มหลัก ปุ่ม "บันทึกภาพตั๋ว" เป็นแบบเส้น
- ตอบรับแบบไหนก็ได้แล้ว → ตราหาย · ไม่ติดไปกับรูปตั๋วที่บันทึก

## ลำดับในเมนู (ไม่ต้องเปลี่ยนเลขไฟล์)
- `MENU_ORDER` ใน `index.html` เช่น `shirt: [1,2,…,9, 27,28, 10,…]` = ลำดับที่โชว์ในแท็บ · เลขไฟล์ไม่เปลี่ยน แขกที่บันทึกไว้ไม่กระทบ
- เพิ่มชิ้นใหม่: อัปไฟล์เลขถัดไป (เช่น `shirt_33.png` + ไอคอน) → เพิ่ม `count` ใน `LAYERS` → ใส่เลข 33 ในตำแหน่งที่อยากให้อยู่ใน `MENU_ORDER`
- เลขที่ไม่อยู่ในรายการ ต่อท้ายเมนูตามเลขเอง · หมวดที่ไม่มีใน `MENU_ORDER` เรียงตามเลขปกติ
