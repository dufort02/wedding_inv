# wedding_inv

การ์ดแต่งงานออนไลน์ Palida & Pachaya — แก้ค่าต่าง ๆ ได้ที่ `CONFIG` ใน `index.html`

## ช่องทางร่วมอวยพร (RSVP แบบที่ 2)

แก้ที่ `CONFIG.GIFT` ใน `index.html`: `BANK`, `NUMBER`, `NAME`
ถ้ามี QR พร้อมเพย์ ให้อัปโหลดเป็น `images/promptpay.png` (ไม่มีไฟล์ = ไม่แสดง QR)

## เชื่อม RSVP กับ Google Sheet

1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `Code.gs` → บันทึก
3. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** → ประเภท **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
4. อนุญาตสิทธิ์ แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
5. วาง URL ใน `CONFIG.RSVP_ENDPOINT` ของ `index.html`

ทดสอบ: เปิด URL `/exec` ในเบราว์เซอร์ ต้องเห็น `{"ok":true,...}`

> แก้ `Code.gs` ภายหลัง ต้อง **ทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่** ทุกครั้ง
> ถ้าเคยสร้างชีต `RSVP` จากโค้ดเวอร์ชันเก่า ให้ลบหรือเปลี่ยนชื่อชีตนั้นก่อน เพราะคอลัมน์เปลี่ยนแล้ว

## อัปเดตสคริปต์เวอร์ชันแอดมิน (ทำครั้งเดียว)

1. เปิด Apps Script ของชีต → วางโค้ดใหม่จาก `Code.gs` ทับทั้งหมด → บันทึก
2. เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน → กด **▶ เรียกใช้** → อนุญาตสิทธิ์ (ครั้งนี้จะขอสิทธิ์ส่งอีเมลเพิ่ม)
   - เพิ่มคอลัมน์ `ปักหมุด`, ตั้ง dropdown/สีของช่อง `แสดงบนเว็บ`, สร้างชีต **สรุป**
3. **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
   (URL `/exec` เดิมใช้ต่อได้ ไม่ต้องแก้ index.html)
4. รีเฟรชหน้า Google Sheet → จะเห็นเมนู **💌 งานแต่ง**
5. **เช็กว่า deploy แล้วจริง:** เปิด URL `/exec` ในเบราว์เซอร์ ต้องเห็น `"version":3` และ `"approval":true`
   ถ้ายังเห็นแค่ `{"ok":true,"msg":"RSVP endpoint is running"}` = เว็บยังใช้สคริปต์ตัวเก่า → ทำข้อ 3 ใหม่ (ต้องเลือก **เวอร์ชันใหม่**)

## เพิ่มชิ้นส่วนตัวละคร

อัปโหลด 2 ไฟล์ต่อ 1 ตัวเลือก โดย**ใช้เลขถัดไป**และ**นามสกุล `.png` ตัวเล็ก**:
- `images/<หมวด>_<เลข>.png` เช่น `images/hair_6.png`
- `images/icons/<ไอคอน>_<เลข>_thumb.png` เช่น `images/icons/hair_6_thumb.png`

ชื่อหมวด/ไอคอนดูได้ที่ `LAYERS` ใน index.html (เช่น ที่คาดผม = `hair_accessories_6.png` + `icons/hair_acc_6_thumb.png`)
เว็บจะเจอไฟล์ใหม่เองอัตโนมัติ ไม่ต้องแก้โค้ด — แต่เลขต้องต่อเนื่อง (ถ้าข้ามเลข จะหยุดหาตรงเลขที่ขาด)

## ทดสอบเกมแต่งตัว

เปิด `https://<ชื่อ>.github.io/wedding_inv/index.html?avatar`

- เข้าหน้าแต่งตัวทันที (ไม่มีหน้าปก/เพลง) → กด "ใช้ตัวนี้เข้างาน" → เห็น **บัตรเชิญ** เหมือนเว็บจริง + ปุ่มบันทึกรูป 2000px
- ด้านล่างมี **ตัวอย่างการ์ดอวยพรทั้ง 2 แบบ** (โพลารอยด์ / โปสการ์ด) ลองเปลี่ยนข้อความ ป้าย และสีการ์ดได้
- **ไม่บันทึกอะไรเลย และไม่ส่งเข้าชีต** — ไม่กระทบข้อมูลแขกจริงที่อยู่ในเครื่องเดียวกัน ส่งลิงก์ให้เพื่อนช่วยลองได้

## พฤติกรรมของแขก (สรุป)

- **ครั้งแรก:** เปิดคำเชิญ → แต่งตัวละคร → ได้บัตรเชิญ → ตอบ RSVP
- **กลับมาอีกครั้ง (เครื่อง/เบราว์เซอร์เดิม):** ข้ามหน้าแต่งตัว เห็นบัตรเชิญ + "คุณตอบรับแล้ว" พร้อมปุ่ม **แก้ไขคำตอบ**
- **แก้ไขคำตอบ:** อัปเดตแถวเดิมในชีต (ไม่เพิ่มแถวซ้ำ) — ถ้าแก้ข้อความอวยพร จะกลับไป "รออนุมัติ"; ถ้าแก้อย่างอื่น การ์ดที่อนุมัติ/ปักหมุดไว้ยังอยู่
- **เปลี่ยนเครื่อง/เบราว์เซอร์** (เช่น เปิดลิงก์ใน LINE แล้วเปิดใน Safari) = เหมือนแขกใหม่ → อาจได้แถวซ้ำ ดูได้ที่ชีตสรุป "ชื่อที่ตอบซ้ำ"
- **รูปตัวละคร:** ส่งเข้า Drive เป็น PNG พื้นใส 1500×1500 (พิมพ์สติกเกอร์ ~12 ซม. ที่ 300dpi) · ปุ่ม "บันทึกรูปตัวละคร" ให้แขกโหลด 2000×2000
- ก่อนใช้จริง ตั้ง `SHOW_SKIP: false` ใน index.html (ซ่อนปุ่ม "ข้าม" หน้าแต่งตัว)

## การจัดการคำอวยพร (แอดมิน)

ทุกอย่างทำใน Google Sheet ชีต `RSVP` — แก้แล้วหน้าเว็บเห็นทันที

| ต้องการ | วิธี |
|---|---|
| อนุมัติให้ขึ้นเว็บ | ช่อง **แสดงบนเว็บ** → `แสดง` หรือเลือกหลายแถว → เมนู 💌 → ✅ |
| ซ่อน | → `ไม่แสดง` หรือเมนู 💌 → 🚫 |
| ปักหมุดไว้บนสุด | ติ๊กช่อง **ปักหมุด** หรือเมนู 💌 → 📌 (การ์ดมีเทปแดงและหัวใจ) |
| แก้คำผิด | แก้ในช่อง `คำอวยพร` / `ชื่อ` ได้เลย |
| ลบถาวร | ลบทั้งแถว (รูปตัวละครยังอยู่ในโฟลเดอร์ Drive `Wedding Guest Avatars`) |

**โหมดอนุมัติ** — คำอวยพรใหม่จะเป็น `รออนุมัติ` (สีเหลือง) จนกว่าจะเปลี่ยนเป็น `แสดง`
ปิดโหมดนี้: ตั้ง `REQUIRE_APPROVAL = false` ใน Code.gs **และ** `WISH_APPROVAL: false` ใน index.html

**อีเมลแจ้งเตือน** — ทุกครั้งที่มีคนตอบ จะส่งไปที่อีเมลเจ้าของชีต
เปลี่ยนผู้รับ: `NOTIFY_EMAIL = 'a@gmail.com,b@gmail.com'` ปิด: `NOTIFY_EMAIL = ''`
(Gmail ส่งได้ประมาณ 100 ฉบับ/วัน) ทดสอบ: เมนู 💌 → ✉️

**ชีตสรุป** — อัปเดตเองอัตโนมัติ: จำนวนแขกที่มา, นับตามอาหาร, ส่งของขวัญ, อวยพรออนไลน์,
คำอวยพรรออนุมัติ, รายชื่อแพ้อาหาร และ **ชื่อที่ตอบซ้ำ** (แขกกดส่งซ้ำ → จำนวนคนอาจเกิน ให้ลบแถวที่ซ้ำ)
ถ้าย้าย/เพิ่มคอลัมน์ในชีต RSVP ให้กดเมนู 💌 → 🔧 เพื่อสร้างชีตสรุปใหม่

## สไลด์โชว์คำอวยพรในงาน

เปิด `https://<ชื่อ>.github.io/wedding_inv/wishes.html` บนจอ/โปรเจกเตอร์ แล้วกด **F** (หรือดับเบิลคลิก) ให้เต็มจอ

- วนแสดงคำอวยพรที่ `แสดง` ทีละใบ (ใบที่ปักหมุดขึ้นก่อน) ข้อความยาวจะค้างนานขึ้น
- คำอวยพรใหม่ที่อนุมัติระหว่างงานจะเด้งขึ้นเป็นใบถัดไป (เช็กทุก 45 วินาที)
- มุมขวาล่างมี QR ให้แขกสแกนมาเขียนคำอวยพร
- ปุ่ม: `→`/`Space` ถัดไป, `←` ย้อน, `P` หยุด/เล่น, `F` เต็มจอ

## สมุดอวยพร (Wishes)

คำอวยพรจากทุกแบบที่แขกติ๊ก "แสดงบนสมุดอวยพร" จะขึ้นหน้าเว็บหลังแอดมินอนุมัติ (ดูหัวข้อการจัดการด้านบน)

ถ้ายังไม่ได้ใส่ `RSVP_ENDPOINT` เว็บจะอยู่ใน **โหมดทดสอบ** — คำตอบเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น
